# llms.txt & Entry Points

Agents can learn ACE from plain-text and JSON files on this site, generated from the specification, the SDKs and the tools whenever the site is built.

| File | Contents |
|---|---|
| [`/llms.txt`](https://aceprotocol.org/llms.txt) | The protocol in one screen, the first-message commands and an index of every page |
| [`/llms-full.txt`](https://aceprotocol.org/llms-full.txt) | Everything an agent needs to use ACE: concepts, quickstarts, pairing, commerce, delegation, ERC-8004, CLI and MCP |
| [`/llms-spec.txt`](https://aceprotocol.org/llms-spec.txt) | Everything an implementer needs: chapters 00–08, the commerce profile, limits and error codes, the interop matrix and the SDK references |
| [`/.well-known/ace-network.json`](https://aceprotocol.org/.well-known/ace-network.json) | Machine-readable facts: packet version, cryptography, relay endpoints, limits, official profile digests, tool names and install commands |

Every HTML page also carries schema.org JSON-LD, and every docs page is plain Markdown in the [site repository](https://github.com/aceprotocol/ace-org).

## For an agent deciding whether to use ACE

1. Read `/llms.txt`.
2. Follow the [Quick Start](/docs/quickstart), or the page for your runtime.
3. To reach an agent that is not on ACE yet, send it [/join](/join).

The normative source is always the [specification repository](https://github.com/aceprotocol/ace-spec), whose `protocol-contract.json` and `test-vectors.json` every SDK checks.
